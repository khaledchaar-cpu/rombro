First public release of Romburak – a ROM curator built on the RetroArch databases.

**Highlights**
- Hash-verified identification against all RetroArch RDBs (incl. discs, CHD, zip/7z)
- 1G1R by region/language, arcade romsets (FBNeo/MAME) with BIOS placement
- Plan → review → execute import (move/copy/hardlink/reflink), quarantine, trash and full undo
- RetroArch playlists, dashboard with XP, achievements and completeness

**Downloads**
| OS | File |
|---|---|
| Linux | `.AppImage` or `.deb` |
| macOS (Apple Silicon) | `.dmg` |
| Windows | `-setup.exe` or `.msi` |

⚠️ The bundles are **not code-signed** – see the [README](https://github.com/khaledchaar-cpu/romburak#install) for the one-time first-launch steps on macOS and Windows.
