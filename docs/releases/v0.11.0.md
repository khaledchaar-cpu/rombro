### Library maintenance
- "Audit library" now finds bit-identical copies across the whole library (also across systems) and moves the extras to the trash (rule "Duplicate in the library", undoable).
- Arcade sets: the copy a core knows under its file name stays, then the best core (FBNeo, MAME, older MAME). BIOS sets (one per core), `_bios`, game and multi-disc folders are left alone.

### Import

- The plan panel sits above the last-run report.

### Fixes
- Planning no longer crashes (stack overflow) when a discarded duplicate already lies in the trash.
- Trash targets are unique ignoring case – imports on case-insensitive shares (CIFS/SMB) no longer stop with "already exists".
